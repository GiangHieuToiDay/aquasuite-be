# UC-17.1 – Look up Inventory

> English version of `UC-17.1-use-case-specification.vi.md` (the Vietnamese version is the source; keep both in sync). Written to match the **current code**. Messages are quoted exactly as they appear on the screen (Vietnamese).

|  |  |  |  |
| :-: | :-- | :-: | :-- |
| Primary Actors | Shop Owner, Accountant | Secondary Actors | None |
| Created By | Pham Van Nam | Created Date | 24/11/2026 |
| Description | As the Shop Owner or an Accountant, I want to look up the real-time stock of each product (SKU), filter the items that are running low or out of stock, and view the stock movement history of a SKU, so that I know how much is in stock, how much is reserved and when more must be purchased. The use case is read-only and does not change the stock. |  |  |
| Preconditions | 1. The user is logged in with the Shop Owner or Accountant role.<br>2. The SKUs exist in the product catalog and have a stock record. |  |  |
| Normal Flow | **Look up inventory**<br>1. The user opens the Inventory Management page.<br>2. The system displays the inventory list per SKU, 10 rows per page, the most recently changed SKU on top, with the line "Hiển thị <số dòng> / <tổng số> SKU". Each row shows Sản phẩm / SKU, Tồn thực tế (on hand), Đang giữ (reserved), Khả dụng (available), Ngưỡng min (minimum threshold), Trạng thái (Còn hàng, Sắp hết, Hết hàng) and the action Chi tiết (Details).<br>3. The user types a keyword in the "Tên sản phẩm hoặc mã SKU…" field and/or selects a Status.<br>4. The system finds the SKUs that match the keyword, applies the filters and displays the result with the Available quantity and the Status recalculated for each row (GBR-IV-01, GBR-IV-02).<br>5. The user chooses "Chi tiết" on a SKU.<br>6. The system displays the "Chi tiết tồn kho — <SKU>" dialog with Tồn thực tế, Đang giữ, Khả dụng, Ngưỡng tối thiểu and the "Lịch sử thẻ kho gần nhất" (latest stock card history) section (up to 20 movements, newest first) with the columns Thời gian, Loại, Số lượng, Tồn sau, Chứng từ and Ghi chú. The use case ends. |  |  |
| Alternative Flows | **Step 3_Show low-stock items only**<br>1. The user selects the "Chỉ hàng tồn thấp" (Low stock only) checkbox.<br>2. The system shows only the SKUs whose minimum threshold is greater than 0 and whose Available quantity is less than or equal to the threshold. Continue at step 5.<br><br>**Step 3_Filter by status**<br>1. The user selects the Status "Còn hàng", "Sắp hết" or "Hết hàng".<br>2. The system shows only the SKUs with that status (GBR-IV-02). Continue at step 5.<br><br>**Step 2_No result**<br>1. If no SKU matches the keyword and the filters, the system displays “Không tìm thấy SKU phù hợp.”<br>2. The user chooses "Đặt lại" (Reset) to clear the keyword and the filters. Return to step 2.<br><br>**Step 2_Change page**<br>1. When the list has more than one page, the user chooses "Trang trước" or "Trang sau".<br>2. The system displays the corresponding page with the line "Trang <số> / <tổng số trang>".<br><br>**Step 6_No movements yet**<br>1. If the SKU has no stock movement yet, the "Lịch sử thẻ kho gần nhất" section displays “Chưa có biến động tồn kho nào.”<br>2. The user closes the details dialog. The use case ends. |  |  |
| Exception Flow | **Step 1_No permission**<br>1. If the user is not signed in or the session has expired, the system displays “Chưa xác thực hoặc phiên đăng nhập đã hết hạn”.<br>2. If the user is not a Shop Owner or an Accountant, the system rejects the request and displays “Bạn không có quyền thực hiện thao tác này”.<br>3. The system does not display any stock data. The use case ends. |  |  |
| Postconditions | 1. The inventory list, or the details and the stock card history of a SKU, are displayed.<br>2. The on-hand quantity, reserved quantity and threshold of every SKU are not changed.<br>3. When the user has no permission, no stock data is displayed. |  |  |

## Business Rules
| GBR-ID | Rule Statement | Applies To | Rationale | Enforced By |
| :-: | :-- | :-: | :-- | :-- |
| **GBR-IV-01** | The available quantity of a SKU = on-hand quantity − reserved quantity. | UC-17.1 (step 4, step 6) | Reserved goods cannot be sold again, so the sellable quantity is the available quantity. | System (inventory service) |
| **GBR-IV-02** | SKU status: "Hết hàng" (Out of stock) when the available quantity is less than or equal to 0; "Sắp hết" (Low stock) when the minimum threshold is greater than 0 and the available quantity is less than or equal to the threshold; otherwise "Còn hàng" (In stock). A minimum threshold of 0 means the SKU is not monitored for low stock. | UC-17.1 (step 4, status filter of step 3) | Show at a glance which items need to be restocked. | System (inventory service) |

## Out of Scope (not supported by the current code or covered by another use case)

| Item | Note |
| :-- | :-- |
| Configuring the minimum and maximum threshold of a SKU | Covered by UC-17.2 (the "Ngưỡng" button is for the Shop Owner only) |
| Manual stock adjustment, stock counting | Separate use cases |
| Viewing the individual reservations of a SKU | Covered by the stock reservation management use case |
| Looking up several warehouses | The system currently has only one main warehouse |
| Exporting the inventory list to a file | Not available |
